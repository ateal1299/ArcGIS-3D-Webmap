# Assignment 5 – ArcGIS 3D Web Map

## Project Overview

This project is an interactive 3D web map that highlights locations that are important to my personal life, education, and outdoor recreation.

## Features

This project includes colored markers that indicate important locations to my personal life, and include a zoom feature when clicking on the markers. The map also includes a search feature to search for specific cities.
